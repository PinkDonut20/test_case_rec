# Test task baseline: Document preprocessing + OCR + field extraction

Сделал быстрый Google Colab ноутбук без внешних API:

- `colab_document_ocr_pipeline.ipynb`

## Что реализовано

1. Выравнивание документа на фото (OpenCV, поиск 4-угольного контура + perspective transform).
2. OCR текста (EasyOCR, локально, CPU/GPU).
3. Извлечение структурированных полей через **обязательный LLM-этап**:
   - `full_name`
   - `birth_date`
   - `document_number`
4. Сохранение результатов:
   - выровненное изображение
   - изображение с детекциями/текстом
   - JSON с полями и полным OCR

## Архитектура извлечения (как просили)

- Шаг 1: OCR вычленяет текст + боксы.
- Шаг 2: текст нормализуется (русский приоритет, исправление латиница/кириллица).
- Шаг 3: **LLM обязательно** извлекает ключевые поля в JSON.
- Шаг 4: если LLM ответила невалидно/неполно, включается эвристический fallback по пустым полям.

Итого: основной extractor — LLM, эвристики только как страховка от падений.

## Важные улучшения под русский язык

- Подписи на изображении рисуются через PIL + DejaVuSans, поэтому русский текст не превращается в `????`.
- В JSON сохраняются и `text_raw`, и `text_normalized` (нормализованный русский текст).
- Добавлена нормализация смешанной латиницы/кириллицы (типичная OCR-ошибка для русских документов).
- Добавлен второй JSON-файл в кодировке `utf-8-sig` для более корректного открытия в некоторых редакторах Windows.

## LLM-настройки

- `DOC_LLM_MODEL=TinyLlama/TinyLlama-1.1B-Chat-v1.0` — модель по умолчанию.
- Можно заменить на другую локально доступную модель из HuggingFace.

## Тесты в Colab

Добавлена ячейка smoke tests:
- проверяет fallback-эвристику на дату/номер
- проверяет, что `extract_fields` всегда выставляет `llm_used=True`
- проверяет JSON-сериализацию результата

## Как запустить

1. Открой `colab_document_ocr_pipeline.ipynb` в Google Colab.
2. Запусти ячейки сверху вниз.
3. (Опционально) задай `DOC_LLM_MODEL` в отдельной ячейке `os.environ` до инициализации функций.
4. В ячейке `files.upload()` загрузи фото документа.
5. Получишь:
   - визуализацию в ноутбуке
   - файлы в папке `outputs/`

## Интеграция в Docker

Текущая схема готова для контейнера:
- OCR + LLM работают локально
- модель LLM задается env-переменной `DOC_LLM_MODEL`
- поведение легко перенести в REST API и `docker-compose`
